9 · Notas técnicas y decisiones de diseño

Patrón de delegación con fallback

Cada punto de delegación en app.js sigue:
const x = (window.RiskOps && window.RiskOps.módulo) ? RiskOps.módulo.fn(…) : /* inline original */;
Esto garantiza que si el bundle no carga (red lenta, error de CI) la app sigue funcionando exactamente igual que antes.

Factories vs. funciones puras

createShiftController, createAppRouter y createTaskController son factories que necesitan inyección de dependencias (DOM, Firebase, localStorage). No se pueden llamar directamente como RiskOps.X.fn() sin una instancia. Su instanciación es trabajo de Fase 3 / bootstrap.js.

El bundle no se commitea

dist/riskops.bundle.js se genera en CI (npm run build) y en el laboratorio local. El source de control solo lleva fase_2/src/ y fase_2/build/build.mjs. Task #87 agrega ese paso al workflow.

Hallazgo de seguridad documentado en pruebas

sanitizeAnnouncementHTML elimina la etiqueta <script> pero el texto interno queda visible como texto plano (no ejecutable, no XSS). No es una vulnerabilidad real, pero se documenta para revisión cuando este módulo se conecte a producción.
